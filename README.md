# Bitwarden SDK for Swift

This package distributes the GPL-only Bitwarden SDK, including the provider-neutral alias
lifecycle contract and canonical encrypted login alias reference schema version 1.

## Alias integration

Create one stateful `AliasClient` around an injected `AliasProviderAdapter`. The adapter owns its
explicit service endpoint, credential, provider-native models, and transport. Those values must be
loaded from encrypted connection metadata and never cross the common SDK boundary.

```swift
let client = try AliasClient(adapter: adapter)
let alias = try await client.create(
    request: CreateAliasRequest(hostname: "example.com")
)
let reference = try createAliasReference(identity: alias.identity)
```

Stable identity is exactly `connectionId` plus an opaque `aliasId`; the canonical address is an
integrity and display snapshot, not a join key. The version 1 reference has exactly four fields:

```json
{"version":1,"connectionId":"<uuid-v4>","aliasId":"<opaque string>","address":"<canonical address>"}
```

Adapters return only canonical records and sanitized `AliasError` values. A mutation whose response
is lost must surface as `OutcomeUnknown` and be reconciled, never blindly replayed. The SDK exposes
pure reference codecs, journal merge/reduction, and dry-run/apply reconciliation functions; the host
retains ownership of encrypted persistence and ordinary vault save paths.

## Generated source boundary

Files under `Sources/BitwardenSdk` that begin with the UniFFI autogenerated notice are generated SDK
wire bindings. Do not edit or duplicate their models manually. Handwritten package tests and archive
verification scripts consume that generated surface without redefining it.

The exact source, workflow, artifact, SBOM, provenance, binary hashes, and supported slices are
recorded in `ALIAS_SDK_PROVENANCE.json`.

The distributed XCFramework supports arm64 iOS devices and arm64 iOS simulators. Debug and local
symbols are stripped deterministically; all externally defined static-link symbols are preserved.
